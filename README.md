## The entry

`main.ts` writes exactly one Wi-Fi network name — 32 characters or fewer — to `entry.txt`:

```
ThisIsTheReasonWeBrokeUp
```

One name in a phone's network list, and a passer-by instantly knows the whole story: someone's relationship ended, and this is why.

## Run

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` sets the output directory (defaults to `/output`).
